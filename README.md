# vivo 广告计划助手（独立扩展 · V0.1 界面版）

这个项目是**全新的 Chrome 扩展**，不依赖、不修改旧 LoveExtension。

## 当前已实现

- 在 `https://ad.vivo.com.cn/marketing/newpromotion/plan` 右键页面空白处，选择「批量新建广告」，显示单页弹窗。
- 所有字段均为紧凑的「标签 + 输入框 / 选择框」横向排列。
- 流量分组和具体流量位可分别勾选，全部默认不选。
- 应用与行业/产品关联可新增、删除、选择；推广名称可新增、删除、选择。
- 管理的应用关联与推广名称保存在本浏览器 `chrome.storage.local`。
- 安装定向默认「已安装」；优化目标默认「自定义拉活」。
- 选择头像（256×256、JPG/JPEG/PNG、必须小于 50KB），选择单图或视频文件。
- 填写广告计划名称、转化出价、广告标题、DeepLink、曝光监测地址、点击监测地址。
- 输入检查及界面反馈。广告名称将由广告计划名称派生，不单独配置。

## 尚未实现（下一阶段）

- **没有调用 vivo 接口，也没有点击真实网站中的创建按钮。**
- 「开始创建广告」只检查表单并提示下一阶段需要接入自动化，不会新建计划或广告。
- 本地选择的图片/视频只在当前页面有效；刷新后要重新选文件。不会偷偷上传或保存这些素材。

## 安装

1. Chrome 打开 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择这个项目文件夹 `vivo-plan-extension`。
5. 打开 vivo 新版广告计划页并刷新一次。
6. 在**页面空白处**右键，选择「批量新建广告」。

> 注：浏览器右键菜单的入口作用于网页空白区域，不在浏览器地址栏或标签栏显示。

## 下一步要对接的单计划流程

在真实登录的测试账号中，手动走通一次「新建广告 → 新建推广计划 → 填写计划信息 → 保存并新建广告 → 填写广告信息 → 提交」，记录每一步的网页行为、导航 URL、关键下拉菜单、校验反馈及最终成功结果；然后才将表单与真实网站的 DOM 对接。
